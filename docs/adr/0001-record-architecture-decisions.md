# ADR 0001 — Record architecture decisions

**Status:** accepted · **Date:** 2026-09-06

## Context

Six people, five days, and a set of decisions where the reasoning matters more than the choice —
because judges ask "why", and because a teammate who does not know the reason will undo it.

## Decision

Record every decision that constrains someone else's work as a short ADR in `docs/adr/`,
numbered sequentially, in this format: Context, Decision, Consequences.

Write one if you spent more than twenty minutes choosing.

## Consequences

- Judges can read why, not just what. This is a scoring surface.
- A teammate who disagrees argues with the reasoning rather than silently reverting.
- Costs about ten minutes per decision.
